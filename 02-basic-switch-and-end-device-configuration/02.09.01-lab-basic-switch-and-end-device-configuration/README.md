## Описание сценария

Новый коммутатор пересылает кадры между подключенными к нему устройствами без всякой настройки, но перед вводом в работу он получает базовую настройку: имя устройства, пароли на вход с консоли, по сети и в привилегированный режим, предупреждающий баннер. Для управления по сети коммутатору нужен IP-адрес: его задают на виртуальном интерфейсе VLAN 1 и включают этот интерфейс. Компьютерам одной сети для обмена данными нужны IP-адреса и маски подсети из этой сети. Настройка, сохраненная в загрузочную конфигурацию, сохраняется и после перезагрузки устройства.

Согласно сценарию, менеджер просит вас, нового специалиста по обслуживанию локальных сетей, показать, как вы настраиваете небольшую локальную сеть. Вам нужно выполнить базовую настройку двух коммутаторов, задать IP-адреса коммутаторам и компьютерам и убедиться, что все устройства обмениваются данными. Это лабораторная работа на проверку навыков: в ней перечислены требования к результату, а команды для их выполнения вы выбираете сами.

## Задачи лабораторной работы

- Выполнить базовую настройку коммутаторов S1 и S2
- Настроить IP-адресацию коммутаторов и компьютеров
- Сохранить конфигурацию коммутаторов
- Проверить связь между всеми устройствами

## Описание топологии

Топология состоит из двух коммутаторов S1 и S2, соединенных между собой, и двух компьютеров: компьютер PC-A подключен к коммутатору S1, а компьютер PC-B — к коммутатору S2.
