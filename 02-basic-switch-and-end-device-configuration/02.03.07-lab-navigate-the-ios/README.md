## Описание сценария

Сетевые устройства настраивают в интерфейсе командной строки (CLI) их ОС. Команды в нем разделены по режимам: в пользовательском режиме EXEC доступны только команды просмотра, в привилегированном режиме EXEC — все команды просмотра и управления устройством, а в режиме глобальной конфигурации изменяют настройки. Приглашение командной строки показывает текущий режим. Контекстная справка по вопросительному знаку перечисляет команды и параметры, допустимые в этом месте строки, а клавиша Tab дописывает начатую команду. Новое устройство, у которого еще нет IP-адреса, настраивают через его консольный порт: к нему подключают компьютер консольным кабелем.

Согласно сценарию, в небольшую компанию поступил новый коммутатор S1, и его консольный порт уже соединен консольным кабелем с компьютером администратора PC1. Прежде чем настраивать коммутатор, вам, начинающему сетевому администратору, нужно освоиться с его интерфейсом командной строки: подключиться к консоли с компьютера PC1, научиться пользоваться справкой и переходить между режимами, а затем с помощью справки установить на коммутаторе часы и разобраться в его сообщениях об ошибках ввода.

## Задачи лабораторной работы

- Подключиться к консоли коммутатора S1 с компьютера PC1 и изучить контекстную справку
- Изучить пользовательский и привилегированный режимы EXEC и перейти в режим глобальной конфигурации
- Установить часы коммутатора S1 с помощью контекстной справки
- Изучить сообщения коммутатора об ошибках ввода команд
- Проверить настройку часов

## Описание топологии

Топология состоит из компьютера PC1 и коммутатора S1: консольный кабель соединяет порт RS232 компьютера с консольным портом коммутатора.
