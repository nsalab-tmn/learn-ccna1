### Вопрос 1 (один ответ)

Сайты у пользователя перестали открываться. Сначала он хочет посмотреть, какие IPv4-адрес, маска подсети и шлюз по умолчанию настроены на его компьютере. Какой командой это делают?

- А: ipconfig
- Б: ping ya.ru
- В: show running-config
- Г: show ip interface brief

### Вопрос 2 (один ответ)

В выводе `show ip interface brief` на новом коммутаторе строка Vlan1 выглядит так: `unassigned … administratively down down`. Что это означает?

- А: SVI выключен и без адреса: нужны ip address и no shutdown
- Б: К коммутатору пока не подключен кабелем ни один компьютер
- В: Интерфейс Vlan1 неисправен, и коммутатор нужно заменить
- Г: Коммутатор не пересылает данные между портами, пока интерфейс выключен

### Вопрос 3 (один ответ)

С PC1 выполнили `ping 192.168.1.20` и получили: Sent = 4, Received = 4, Lost = 0. Что доказывает этот результат?

- А: У PC1 есть доступ в Интернет через маршрутизатор
- Б: PC1 и устройство 192.168.1.20 связаны по сети
- В: Скорость соединения между ними достаточная для работы
- Г: Адрес 192.168.1.20 свободен, и его можно назначить PC1
