### Вопрос 1 (один ответ)

Администратор вводит IPv4-адрес компьютера в свойствах сетевого адаптера. Какая запись соответствует формату IPv4-адреса?

- А: 172.16.30.254
- Б: 172.16.300.25
- В: 172.16.30.254.1
- Г: 172:16:30:254

### Вопрос 2 (один ответ)

Администратору нужно подключаться к коммутатору второго уровня по SSH из другого здания. Где на коммутаторе нужно настроить IP-адрес для этого?

- А: На виртуальном интерфейсе коммутатора (SVI)
- Б: На порту Ethernet, к которому подключен кабель
- В: Нигде: коммутатору второго уровня IP-адрес не нужен
- Г: На консольном порту коммутатора

### Вопрос 3 (один ответ)

Почему интерфейс коммутатора, которому назначают IP-адрес для удаленного управления, называют виртуальным?

- А: Он работает только по беспроводной связи, а не по кабелю
- Б: У него нет своего физического оборудования, он создан программно
- В: Он существует только до перезагрузки коммутатора, потом его создают заново
- Г: Он виден только тем, кто подключился к коммутатору по сети
