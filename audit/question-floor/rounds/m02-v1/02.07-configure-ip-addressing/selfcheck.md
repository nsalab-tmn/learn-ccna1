### Вопрос 1 (один ответ)

На новом коммутаторе администратор ввел interface vlan 1, затем ip address 10.10.5.2 255.255.255.0 и вышел из режима настройки интерфейса. Однако связи с коммутатором по адресу 10.10.5.2 у компьютера из той же подсети нет. Какова наиболее вероятная причина?

- А: Интерфейс vlan 1 не включен командой no shutdown
- Б: IP-адрес нужно было назначить физическому порту
- В: Не задан шлюз по умолчанию командой ip default-gateway
- Г: Изменения начнут действовать только после сохранения

### Вопрос 2 (несколько ответов)

Ноутбук в офисе автоматически получает и IPv4-, и IPv6-адрес. Какие два механизма могут назначить ему IPv6-адрес? (верны два варианта)

- А: DHCPv6
- Б: SLAAC
- В: DNS
- Г: DHCP для IPv4

### Вопрос 3 (один ответ)

В настройках ПК указан адрес DNS-сервера 8.8.8.8. Для чего ПК обращается по этому адресу?

- А: Чтобы получить от него свой IP-адрес, маску подсети и шлюз по умолчанию
- Б: Чтобы узнать IP-адрес сайта по его имени, например ya.ru
- В: Чтобы через него отправлять весь трафик в Интернет
- Г: Чтобы проверить, есть ли у ПК доступ в Интернет

### Вопрос 4 (один ответ)

На ноутбуке включено «Получить IP-адрес автоматически». Откуда ноутбук берет адрес, когда подключается к сети?

- А: Берет адрес из своих прошлых настроек, сохраненных в Windows
- Б: Придумывает свободный адрес сам и проверяет, не занят ли он
- В: Запрашивает у сервера, который выдает ему адрес, маску, шлюз и DNS
- Г: Получает его от DNS-сервера, адрес которого задан в настройках подключения

### Вопрос 5 (один ответ)

ПК с адресом 192.168.1.10 и маской 255.255.255.0 обменивается данными с устройствами своей сети, но не получает ответа ни от одного устройства из других сетей. Какой параметр, скорее всего, не задан?

- А: IPv4-адрес
- Б: Адрес DNS-сервера
- В: Маска подсети
- Г: Шлюз по умолчанию
