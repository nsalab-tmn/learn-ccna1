### Вопрос 1 (один ответ)

Новый коммутатор только что распакован и включен, ни одной настройки на нем нет. Администратор стоит рядом с ним. Как он откроет командную строку коммутатора?

- А: Через консольный порт, соединив его с ноутбуком кабелем консоли
- Б: По сети по SSH, подключив ноутбук к любому порту Ethernet коммутатора
- В: Через вспомогательный порт, подключив к нему модем
- Г: На странице настроек в браузере, набрав адрес коммутатора

### Вопрос 2 (один ответ)

Связь с маршрутизатором в другом городе через сеть пропала. К его порту подключен модем на телефонной линии. Через какой порт администратор сможет открыть командную строку, не выезжая на место?

- А: Через порт Ethernet, к которому подключен модем
- Б: Через консольный порт
- В: Ни через какой: без связи по сети к маршрутизатору не подключиться
- Г: Через вспомогательный порт (AUX)

### Вопрос 3 (один ответ)

Администратор подключается к коммутатору из другого здания по сети. Пароль и команды, которые он вводит, не должен прочитать тот, кто перехватит трафик. Какой способ доступа ему подходит?

- А: Протокол Telnet
- Б: Протокол SSH
- В: Протокол Telnet, если на коммутаторе задан длинный надежный пароль
- Г: Консольный порт

### Вопрос 4 (один ответ)

Домашний маршрутизатор обычно настраивают через веб-интерфейс в браузере, а коммутаторы и маршрутизаторы в сети предприятия — через CLI. Какое свойство CLI объясняет такой выбор для сетевых устройств?

- А: Только через CLI устройство можно защитить паролем от посторонних
- Б: CLI не требует знать структуру команд
- В: CLI менее ресурсоемок и работает устойчивее, чем GUI
- Г: CLI доступен только через консольный порт

### Вопрос 5 (один ответ)

На коммутаторе работает та версия ОС, с которой его поставили, и в ней нет функции, нужной сетевому инженеру. Как получить эту функцию?

- А: Подключаться по SSH вместо консоли
- Б: Установить другую программу эмуляции терминала
- В: Настраивать коммутатор через GUI вместо CLI
- Г: Обновить ОС до версии с нужными функциями

### Вопрос 6 (один ответ)

Администратор подключил ноутбук к консольному порту нового коммутатора специальным кабелем. Что ему еще нужно, чтобы работать с CLI коммутатора?

- А: IP-адрес, настроенный на коммутаторе
- Б: Программа эмуляции терминала, например PuTTY
- В: Модем, подключенный к вспомогательному порту
- Г: Веб-браузер для входа в графический интерфейс
