## 2. Самопроверка ↔ лекция

**Нельзя ответить из материала и блокнота:** таких вопросов нет. На все пять вопросов ответ находится либо в material.md, либо в блокноте.

- Вопрос 5 из самого материала 02.07 не решается: материал лишь говорит «настройте IPv4-адрес, маску подсети и шлюз по умолчанию», но не объясняет, зачем нужен шлюз. Ответ даёт строка блокнота N-02.06-11 из предыдущего материала. Без неё учащийся знал бы только по персоне (P-24), что «без шлюза нет Интернета», и выбрал бы Г по привычке, не понимая механизма.
- Вопрос 1 тоже опирается на блокнот, чтобы отбросить дистракторы: Б отвергается по N-02.06-30 (физические порты коммутатора не поддерживают IP-адреса), В — по N-02.06-11 (шлюз нужен для удалённых сетей, а ПК в той же подсети), Г — по N-02.05-05 (изменения текущей конфигурации действуют сразу). Сам материал даёт только положительную часть: «включите виртуальный интерфейс… no shutdown».

**Проверяют только узнавание слова:**

- Вопрос 2 — слова DHCPv6 и SLAAC встречаются один раз, в примечании, без объяснения; чтобы ответить, достаточно их узнать. Дистракторы (DNS, DHCP для IPv4) отсекаются по названиям.
- Вопрос 3 — формально проверяет понимание (нужно отличить DNS от DHCP), но верный вариант почти дословно повторяет примечание вместе с примером ya.ru, поэтому на практике сводится к узнаванию фразы.

**Требуют того, чего не объясняли:** таких вопросов нет. Замечания по неполноте материала, не влияющие на ответы:

- Материал не объясняет, что такое VLAN («Vlan 1 — это не реальный физический интерфейс, а виртуальный» — и всё), что делает SLAAC, и почему после `ip address` интерфейс остаётся выключенным. Для вопроса 1 хватает фразы «включите… no shutdown», но «почему интерфейс по умолчанию выключен» учащийся не знает.
- Последняя строка примера кода `ip default-gateway 192.168.1.1` в тексте раздела не описана: учащийся видит её в листинге, но не знает, зачем она коммутатору. Вопрос 1 использует её как дистрактор В — отсечь удаётся только по блокноту (N-02.06-11) и по условию «из той же подсети».
- В вопросе 4 вариант В говорит, что сервер выдаёт «адрес, маску, шлюз и DNS»; материал прямо пишет лишь «получит настройки адреса, необходимые для связи по сети», а перечень из четырёх параметров приводит в абзаце о том, что пришлось бы вводить вручную. Вывод делается по сопоставлению двух абзацев и по рисунку 3 (Obtain DNS server address automatically).
