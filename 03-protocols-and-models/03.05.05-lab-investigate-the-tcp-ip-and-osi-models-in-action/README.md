## Описание сценария

Модель OSI и модель TCP/IP описывают передачу данных по сети как работу нескольких уровней. На отправляющем устройстве каждый уровень добавляет к данным свой заголовок: прикладной уровень формирует запрос HTTP, транспортный добавляет заголовок TCP с номерами портов, сетевой — заголовок IP с адресами узлов, канальный — заголовок Ethernet с MAC-адресами. Это инкапсуляция. Принимающее устройство снимает заголовки в обратном порядке и передает данные уровню выше. Данные вместе с заголовком своего уровня называются единицей данных протокола (PDU).

Согласно сценарию, в учебной лаборатории к серверу Web-Server напрямую подключен компьютер Web-Client. Сервер отвечает на DNS-запросы об имени www.osi.local и отдает по этому имени веб-страницу. Прежде чем изучать протоколы по отдельности, вам нужно проследить в режиме «Симуляция», какие события происходят в сети, когда браузер компьютера открывает страницу, и какие сведения каждый уровень модели OSI добавляет к данным.

## Задачи лабораторной работы

- Проверить начальные настройки компьютера Web-Client
- Сгенерировать трафик HTTP в режиме «Симуляция»
- Изучить уровни модели OSI и заголовки PDU запроса и ответа HTTP
- Изучить события протоколов ARP, DNS и TCP
- Проверить результаты в режиме «Лаборатория»
