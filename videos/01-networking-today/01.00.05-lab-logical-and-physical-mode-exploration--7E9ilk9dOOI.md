## Цель для обучающегося

Обучающийся должен получить на своём компьютере работающий Packet Tracer: найти скачанный установщик, пройти мастер установки с настройками по умолчанию, при первом запуске ответить на запросы (многопользовательский режим, брандмауэр Windows) и войти в приложение, понимая, что гостевой режим ограничен тремя сохранениями.

Текст темы (1.0.3) даёт только два шага: «сохраните файл (ссылки для Windows / macOS / Ubuntu-Debian)» и «запустите программу установки». Видео добавляет (1) что именно спрашивает мастер установки и какие ответы по умолчанию — путь `C:\Program Files\Cisco Packet Tracer 8.0`, ярлыки; (2) три диалога первого запуска — multi-user, брандмауэр, окно входа; (3) смысл входа с учётной записью: без него «Continue as a Guest» и лимит на сохранение файлов; флажок «Keep me logged in» на 3 месяца. Часть про вход на `www.netacad.com` и меню Resources → Download Packet Tracer к нашей раздаче не относится.

## Предложение по пересборке

**Формат:** `текст + иллюстрация` (пошаговая инструкция со скриншотами мастера установки той версии PT, которую курс раздаёт по OneDrive-ссылкам). Видео здесь избыточно: половина ролика — логин на netacad.com и страница загрузки, которых у нас нет; вторая половина — стандартный мастер Inno Setup, который и так проходится кнопкой Next. Если всё же нужен ролик — `видео с генерированным голосом (код-рендер)` ≤ 1:30 только по установке и первому запуску. Для симулятора ничего не требуется (CLI нет).

Сцены (для текста или короткого ролика):

1. **Скачать** → скриншот папки Downloads с файлом установщика (имя файла текущей раздачи, размер) → «Скачайте установщик для своей ОС по ссылке в тексте и запустите его.»
2. **Лицензия** → страница License Agreement, отмечен «I accept the agreement» → «Примите лицензионное соглашение.»
3. **Каталог, папка меню, ярлыки** → три страницы мастера с значениями по умолчанию (`C:\Program Files\Cisco Packet Tracer <версия>`, ☑ desktop shortcut) → «Всё оставляем по умолчанию — Next, Next, Install.»
4. **Завершение** → страница Completing… с ☑ Launch Cisco Packet Tracer → «Finish — Packet Tracer запустится сам.»
5. **Первый запуск** → диалог multi-user (Yes), предупреждение брандмауэра (разрешить для частных сетей) → «Два вопроса при первом запуске: многопользовательский режим и брандмауэр.»
6. **Вход** → окно входа PT: вход с аккаунтом / Continue as a Guest; ☑ Keep me logged in → «Без входа гость может сохранить файл только 3 раза. „Keep me logged in“ запоминает вас на 3 месяца; выйти — File → Exit and Logout.» *(Проверить на актуальной версии PT: в 8.2+ вход идёт через Skills for All / NetAcad и экран отличается.)*
7. **Готово** → главное окно PT с вкладками Logical/Physical → переход к видео 1.0.4.

Ассеты: 8–10 скриншотов актуального установщика и окна входа (снять заново с версии из OneDrive, не брать из ролика — там PT 8.0.0 BETA Build 126 и старый экран входа).

**Замечания к оригиналу:** страница загрузки на экране предлагает 7.3.1, а установлен 8.0.0 BETA Build 126 — несоответствие, которое в пересборке исчезает само; «Continue as a Guest… up to 3 times» верно для PT 7.x/8.0, в новых версиях гостевой режим ограничен иначе — уточнить при пересъёмке.
