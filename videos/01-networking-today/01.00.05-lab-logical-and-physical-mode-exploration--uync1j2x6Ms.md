## Цель для обучающегося

После просмотра обучающийся должен ориентироваться в главном окне Packet Tracer: знать категории и подкатегории нижней панели устройств, уметь разместить маршрутизатор, коммутатор и конечные устройства, соединить их прямым медным кабелем с выбором интерфейсов на каждом конце, переключиться в Physical-вид, поставить устройства в стойку, прибрать кабели (Manage Cable / Manage All Cables on Device), осмотреть лицевую и заднюю панели (Inspect Front / Inspect Rear), включить-выключить питание маршрутизатора и подключить новое устройство к конкретному порту.

Текст темы (1.0.4) описывает только три главных меню и особые команды меню File — **Open Samples** и **Exit and Logout**. Видео (а) вообще не показывает меню File, зато (б) подробно проходит всё, что нужно для лабораторной работы 1.0.5: категории нижней панели (Часть 1 лабораторной), Physical-вид, стойку и инспекцию устройств (Часть 2), подключение конечных устройств и кабели (Часть 3), установку нового устройства на стойку (Часть 4). То есть видео — демонстрация тех самых действий, которые лаборатория затем требует выполнить в готовой PTPM-сети (Seward / Warrenton).

## Предложение по пересборке

**Формат:** `видео с генерированным голосом (код-рендер)` — скринкаст по актуальной версии Packet Tracer, ~5:00 (оригинал 13:14 сильно растянут паузами и повторами «click… click»). Разбить на два ролика по структуре лабораторной: **(A) «Панель устройств и первая сеть в Logical»** ≈ 2:00 и **(B) «Physical-вид: стойка, кабели, инспекция»** ≈ 3:00. Альтернатива для (A) — `текст + иллюстрация` (одна аннотированная картинка панели с категориями уже почти есть в лабораторной, Часть 1).

Сцены для генератора (A):

1. **Главное окно** → пустое поле, подсветка зон: вкладки Logical/Physical, панель устройств, панель сценария → «Главное окно Packet Tracer: рабочее поле, вкладки логического и физического вида, внизу — панель устройств.»
2. **Категории** → по очереди подсвечиваются Network Devices (Routers / Switches / Hubs / Wireless / Security / WAN Emulation), End Devices (End Devices / Home / Smart City / Industrial / Power Grid), Components (Boards / Actuators / Sensors), Connections (Connections / Structured Cabling), Miscellaneous, Multiuser → одна фраза на категорию.
3. **Размещение** → Routers → 4331 на поле; Switches → 2960 на поле; End Devices → PC, Laptop → «Щёлкните модель, затем место на поле.»
4. **Кабели** → Connections → Copper Straight-Through; PC0: FastEthernet0 → Switch0: FastEthernet0/1; Laptop0: FastEthernet0 → Switch0: FastEthernet0/2; Switch0: GigabitEthernet0/1 → Router0: GigabitEthernet0/0/0 → «На каждом конце кабеля выбираем интерфейс.»
