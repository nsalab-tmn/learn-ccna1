## Цель для обучающегося

Уметь прочитать вывод `show version` и найти в нём: версию и имя образа IOS XE (`Cisco IOS XE Software, Version 16.06.04`, образ `X86_64_LINUX_IOSD-UNIVERSALK9-M`, Everest 16.6.4); время работы (`Router uptime is 4 minutes`); имя и расположение файла образа (`bootflash:isr4300-universalk9.16.06.04.SPA.bin` — платформа ISR4300, universalk9, SPA = подписанный образ, .bin — двоичный файл); причину последней перезагрузки (`Last reload reason: Reload Command`); сведения о лицензиях (пакет `ipbase` — `ipbasek9`, `Permanent`, остальные `None`) и трёхшаговый порядок добавления лицензии (PAK → лицензия по UDI → установка); объём памяти (DRAM `1795999K/6147K` — основная/разделяемая; `4194304K` физической), число интерфейсов (`2 Gigabit Ethernet interfaces`, `2 Serial interfaces`), NVRAM (`32768K bytes of non-volatile configuration memory` — хранит startup-config и регистр конфигурации), flash (`3207167K bytes of flash memory at bootflash:`) и регистр конфигурации (`0x2102` — загрузка IOS из flash и конфигурации из NVRAM; его изменение используется для восстановления пароля).

Текст темы 17.5.5 перечисляет команды `show` с примерами (`show running-config`, `show interfaces`, `show arp`, `show ip route`, `show protocols`, `show version`) и даёт краткое описание полей `show version`. Видео добавляет живой постраничный просмотр реального вывода с объяснением каждого блока, пояснение имени файла образа (platform-featureset.version.SPA.bin), разбор лицензий и смысла 0x2102 с намёком на процедуру восстановления пароля. Для симулятора это эталонный вывод `show version` для модели ISR 4321 с IOS XE 16.6.4.

**Замечания о точности оригинала (учесть при пересборке):**

1. Диктор говорит «roughly 2 gigabytes of DRAM partitioned into main and shared memory» (1 795 999K + 6 147K ≈ 1,8 ГБ) и затем «4 GB physical memory — total DRAM including main and shared». На IOS XE первая цифра — память процесса IOSd, вторая — вся DRAM платформы; оба утверждения приемлемы для уровня курса, но при пересборке точнее: «1,8 ГБ выделено IOS, всего в роутере 4 ГБ».
2. Значение регистра для восстановления пароля (0x2142) не названо — добавить одной фразой вместе с предупреждением вернуть 0x2102.
3. Заголовок `Suite License Information for Module:'esg'` прокручен за край экрана; в эталонном выводе для симулятора его нужно вернуть.
4. Классическая схема лицензирования PAK/UDI относится к IOS XE 16.x; современные версии используют Smart Licensing — упомянуть, что процедура зависит от версии.
5. Imя хоста в ролике — заводское `Router`; промпт `Router>` / `Router#` — хорошо показывает смену режима, оставить.
