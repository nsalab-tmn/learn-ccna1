## Цель для обучающегося

Обучающийся должен понимать, что hex — система с основанием 16 (символы 0–9, A–F; веса 1, 16, 256, 4096), что одна hex-цифра = 4 бита, а байт = 2 hex-цифры, и уметь переводить в обе стороны **через двоичное**: десятичное → 8 бит → две четвёрки → две hex-цифры (197 → 1100 0101 → C5), hex → по 4 бита на символ → 8 бит → десятичное (9F → 1001 1111 → 159); знать запись `0xC5`.

Текст 5.2.1–5.2.4 даёт таблицу эквивалентов и те же два трёхшаговых алгоритма (пример 168 → A8 и D2 → 210). Видео добавляет: (1) веса разрядов hex как степени 16 (4096, 256, 16, 1); (2) **прямой** способ 2A = 2·16 + 10·1 = 42 и объяснение, почему удобнее идти через двоичное (умножать/делить на 16 неудобно); (3) алгоритм вычитания остатка при переводе 197 в биты (197 − 128 = 69, 69 − 64 = 5, 5 − 4 = 1, 1 − 1 = 0) — явно, в столбик; (4) другие числа-примеры (2A, 197/C5, 9F/159), чем в тексте — хороший материал для задач.

## Предложение по пересборке

**Формат:** `анимация Figma (≤ 60 с)` ×2 (197 → C5; 9F → 159) как иллюстрации к 5.2.3/5.2.4 **или** `видео с генерированным голосом (код-рендер)` ~2:30. Контент табличный, хорошо ложится в анимацию «появление цифр». Симулятору ничего не требуется; сценарий годится как шаблон тренажёра (генерировать случайное число 0–255 и вести по шагам: вычитание → четвёрки → hex).

Сцены для генератора:

1. **Основание 16** → символы `0…9 A B C D E F`, веса `4096 256 16 1` → «Шестнадцать символов; одна hex-цифра — четыре бита, байт — две цифры.»
2. **Таблица эквивалентов** → три колонки hex/dec/bin `0…F` → «A = 10 … F = 15.»
3. **2A напрямую** → `2·16 + A·1 = 32 + 10 = 42` → «Можно умножать на веса, но проще через двоичное.»
4. **197 → биты** → столбик вычитаний 197−128=69, 69−64=5, 5−4=1, 1−1=0; биты `11000101` → «Помещается — 1 и вычитаем; нет — 0.»
5. **Биты → hex** → `1100 | 0101` → `12 | 5` → `C | 5` → `0xC5` → «Каждую четвёрку — в одну цифру.»
6. **9F → 159** → `9 = 1001`, `F = 1111` → `10011111` → `128+16+8+4+2+1 = 159` → «Обратно — те же шаги.»

Ассеты: таблица весов 2⁷…2⁰ (две копии по 4 бита), таблица hex/dec/bin, столбик вычитаний, карточка `0xC5`.

**Замечания к оригиналу:** (1) в голосе на 4:01 «convert the eight bit binary number to decimal by first splitting…» — оговорка, на слайде правильно «to hexadecimal»; (2) при пересборке можно явно добавить пример из текста 5.2.3 (168 → A8) и 5.2.4 (D2 → 210), чтобы видео и текст использовали одни числа, либо наоборот оставить разные для большего набора примеров; (3) вычисления верны: 2A = 42, 197 = 0xC5, 9F = 159.
