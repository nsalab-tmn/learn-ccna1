## Цель для обучающегося

Обучающийся должен уметь пользоваться `?` в трёх формах — отдельно (список команд режима), приклеенным к началу слова (`in?` — варианты завершения), после пробела (`interface ?` — следующие ключевые слова/аргументы) — и читать три сообщения проверщика синтаксиса, понимая, где именно ошибка (маркер `^`), почему команда «неоднозначна» и чего не хватает «неполной» команде.

Текст 2.3.3 описывает это словами (три вопроса, на которые отвечает справка; «если процессор не распознаёт команду — отображает возможные ошибки»). Видео добавляет: реальные списки `?` в user EXEC / privileged EXEC / global config (видно, насколько они различаются), приём «часть команды + ?», `--More--` и пробел для следующей страницы, и все три ошибки на одном примере `interface`: `interface 33` → маркер `^` под «3»; `i` → ambiguous, потому что `i?` даёт `interface ip`; `interface` без аргумента → incomplete, решается `interface ?`.

## Предложение по пересборке

**Формат:** `видео с генерированным голосом (код-рендер)` ~2:30: терминал с подсветкой `?` и маркера `^`; списки команд показывать сокращённо (первые 5–6 строк + «…») для скорости, кроме короткого списка user EXEC и списка `interface ?`. Для симулятора — сессия ниже целиком, это готовый тренинг «справка и три ошибки».

Сцены для генератора:

1. **`?` отдельно** → `Switch>?` список из 12 команд; затем `enable`, `Switch#?` с `--More--` (пробел), затем `configure terminal`, `Switch(config)#?` → «Знак вопроса сам по себе — список команд текущего режима; в каждом режиме он свой. --More-- листается пробелом.»
2. **`in?`** → `interface` → «Часть слова и ? без пробела — варианты завершения.»
3. **`interface ?`** → 6 типов интерфейсов → «Команда, пробел, ? — что можно ввести дальше.»
4. **`interface 33`** → маркер `^` под 3, `% Invalid input detected at '^' marker.` → «Маркер показывает, с какого символа IOS перестал понимать команду.»
5. **`i`** → `% Ambiguous command: "i"`; `i?` → `interface  ip` → «Сокращение должно быть однозначным: с i начинаются две команды.»
6. **`interface`** → `% Incomplete command.`; `interface ?` → «Не хватает аргумента — спросите ?.»
7. **Карточка-итог** → три формы `?` и три сообщения проверщика → «? без пробела, ? после пробела, ? отдельно; Invalid input / Ambiguous / Incomplete.»

Ассеты: рендер терминала; карточка с тремя формами `?` и тремя сообщениями.

**Замечания к оригиналу:** фактических ошибок нет. Голос говорит «the next part is either the name of the interface like ethernet, fast ethernet, gigabit ethernet, or maybe vlan or range» — Port-channel пропущен; не критично. На реальном IOS список `?` длиннее, чем в PT, — в документе зафиксирован именно вывод PT (что и нужно для симулятора).
