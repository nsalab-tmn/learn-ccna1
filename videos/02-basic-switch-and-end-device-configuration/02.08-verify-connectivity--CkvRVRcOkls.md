## Цель для обучающегося

Обучающийся должен уметь по выводу `show ip interface brief` найти интерфейс `Vlan1`, прочитать его адрес и два состояния (Status / Protocol), распознать `administratively down` как «выключен командой shutdown» и исправить это `no shutdown`; а также назначить SVI адрес `ip address … маска` и проверить результат повторным `show ip interface brief` (стрелка ↑).

Текст 2.8.1 (две фразы) только анонсирует команду `show ip interface brief` по аналогии с `ipconfig`. Видео — это и есть содержание раздела: (1) как физически подключить консоль в PT (Connections → Console → PC RS 232 → Switch Console); (2) полный вывод `show ip interface brief` на 2960 (Fa0/1–24, Gi0/1–2, Vlan1) и смысл колонок; (3) два разных дефекта — на S1 адрес есть, но интерфейс выключен; на S2 адреса нет вовсе; (4) сообщения `%LINK-5-CHANGED` / `%LINEPROTO-5-UPDOWN` как мгновенная обратная связь. Настройка PC (ipconfig) словами упомянута в тексте, в видео не показана.

## Сценарий

Топология PT (из PKT-файла): **S1** (2960, `192.168.1.2/24`) — Fa0/1 ↔ Fa0/1 — **S2** (2960, `192.168.1.3/24`); **PC-A** (`192.168.1.10/24`) Fa0 ↔ S1 Fa0/6; **PC-B** (`192.168.1.11/24`) Fa0 ↔ S2 Fa0/18. Подписи адресов стоят на схеме над коммутаторами и под ПК. Консольных кабелей вначале нет.

## Предложение по пересборке

**Формат:** `видео с генерированным голосом (код-рендер)` ~2:30 — терминал с подсветкой строки `Vlan1` и колонок Status/Protocol; короткая вставка схемы при подключении консоли. Оставить ссылку на PKT-файл («повторите сами»). Для симулятора — сессия ниже: два устройства, два разных дефекта (shutdown vs нет адреса) — хороший первый диагностический тренинг. Логично сшить в один ролик с 2.8.2 (gex3BaiuQiw, ping) ≈ 4:00: «настроили → проверили интерфейсы → проверили ping».

Сцены для генератора:

1. **Схема** → S1 (192.168.1.2/24) — S2 (192.168.1.3/24), PC-A (.10) на S1 Fa0/6, PC-B (.11) на S2 Fa0/18 → «Нужно убедиться, что адреса стоят на interface vlan 1 обоих коммутаторов.»
2. **Консоль** → Console-кабель PC-A RS 232 → S1 Console; Terminal, OK → «Консольный кабель, терминал с параметрами по умолчанию.»
3. **show ip interface brief (S1)** → таблица, подсветка `Vlan1 192.168.1.2 … administratively down down` → «Адрес есть, но интерфейс выключен администратором.»
4. **no shutdown** → `interface vlan 1`, `no shutdown`, сообщения LINK/LINEPROTO → «Включаем — две строки подтверждают.»
5. **Проверка** → ↑, `show ip interface brief`, `up up` → «Стрелка вверх экономит набор.»
6. **S2** → консоль с PC-B; `show ip interface brief` → `Vlan1 unassigned … administratively down` → «Здесь адреса нет вовсе.»
7. **ip address** → `ip address 192.168.1.3 255.255.255.0`, `no shutdown`, проверка `192.168.1.3 up up` → «Адрес, маска, включить, проверить.»
8. **Карточка** → колонки Status / Protocol и три состояния: `administratively down` (shutdown), `down` (нет линка), `up` → «Читать две последние колонки.»

Ассеты: рендер терминала; мини-топология; карточка состояний интерфейса.
