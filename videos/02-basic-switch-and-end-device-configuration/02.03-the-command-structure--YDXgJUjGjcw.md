## Цель для обучающегося

Обучающийся должен уметь ускорять работу в CLI: дописывать команды клавишей Tab (и понимать, почему `con`+Tab не срабатывает, а `conf`+Tab — да), сокращать команды до однозначного префикса (`en`, `conf t`, `int f 0/1`), листать историю ↑/↓, выходить в privileged EXEC по Ctrl+Z / Ctrl+C, отменять набранную строку Ctrl+C, прыгать по строке Ctrl+A / Ctrl+E, прерывать зависший DNS-поиск по опечатке через Ctrl+Shift+6 и возвращать недопечатанную команду после сообщения syslog через Ctrl+R.

Текст 2.3.5 даёт три таблицы (редактирование строки, `--More--`, прерывания). Видео добавляет: (1) второй способ попасть в CLI в PT — вкладка CLI самого устройства (без PC и терминала); (2) живой пример неоднозначности `con?` → `configure connect`; (3) разницу Tab-дополнения и сокращения («сокращённая команда выполняется, но на экране не разворачивается»); (4) что происходит при опечатке в privileged EXEC (`congh` → `Translating "congh"...domain server (255.255.255.255)`) и как Ctrl+Shift+6 даёт `% Name lookup aborted`; (5) Ctrl+R на реальном оборудовании с настоящими syslog-сообщениями `%LINEPROTO-5-UPDOWN` / `%LINK-3-UPDOWN`. Ctrl+D/K/U/W, Esc B/F из таблицы в видео нет.

Имя узла — `Switch1`. Во второй части — окно **Tera Term** (меню File / Edit / Setup / Control / Window / Help) с реальным коммутатором `Switch`.

## Предложение по пересборке

**Формат:** `видео с генерированным голосом (код-рендер)` ~3:00 — рендер терминала с всплывающими «клавишами» (бейдж `Tab`, `Ctrl`+`Z` и т. п.) в момент нажатия; на экране PT ведь не видно, какая клавиша нажата — это главный недостаток оригинала. Вторую часть (Ctrl+R) рендерить так же, без реального оборудования: syslog-сообщения вставить в тот же терминал. Для симулятора — сессия ниже; тренажёру нужны: Tab-дополнение с теми же правилами однозначности, принятие сокращений, история, `^Z`, Ctrl+C, Ctrl+A/E, эмуляция `Translating "…"…domain server (255.255.255.255)` + `% Name lookup aborted` по Ctrl+Shift+6 и Ctrl+R после асинхронного сообщения.

Сцены для генератора:

1. **Вкладка CLI** → окно Switch1 → CLI → `Press RETURN` → «В Packet Tracer в CLI можно попасть прямо из окна устройства.»
2. **Tab** → `en`⇥ → `enable`; `con`⇥ (ничего) → `con?` → `configure  connect`; `conf`⇥ → `configure`; ` t`⇥ → `terminal` → «Tab дописывает, только если префикс однозначен.»
3. **Сокращения** → `int f 0/1` → `(config-if)#` → «Сокращённая команда выполняется, но не разворачивается.»
4. **История** → `end`; ↑ `end`, ↑ `configure terminal`, ↓ → «Стрелки листают историю.»
5. **Ctrl+Z / Ctrl+C** → `configure terminal` → `^Z` → `#`; `conf t` + Ctrl+C → новая строка → «Оба возвращают в privileged EXEC; Ctrl+C ещё и отменяет набранное.»
6. **Ctrl+A / Ctrl+E** → `configure`, курсор прыгает в начало и в конец → «Прыжки по строке.»
7. **Ctrl+Shift+6** → `congh` → `Translating "congh"...domain server (255.255.255.255)` → `% Name lookup aborted` → «Опечатка в EXEC — IOS ищет хост с таким именем; Ctrl+Shift+6 прерывает.»
8. **Ctrl+R** → `interface g` + три syslog-строки → Ctrl+R → `Switch(config)#interface g` → «Сообщение перебило ввод — Ctrl+R перерисует строку.»
9. **Карточка** → таблица клавиш из 2.3.5 с галочками на показанных → «Остальные (Ctrl+D/K/U/W, Esc B/F) — в таблице темы.»

Ассеты: рендер терминала; бейджи клавиш; карточка-таблица.

**Замечания к оригиналу:** (1) голос: «IOS пытается превратить буквы в IP-адрес» — точнее, IOS трактует неизвестное слово в EXEC как имя хоста для telnet и делает DNS-запрос (`Translating…domain server`); правильное лекарство на постоянной основе — `no ip domain-lookup` (появится в 2.4/10.x); (2) «Ctrl+R не поддерживается в этой версии Packet Tracer» — проверить на текущей версии PT перед пересборкой; (3) нажатия клавиш на экране не видны — при пересборке показывать бейджи; (4) порядок `%LINEPROTO`/`%LINK` в реальном выводе — как на экране (сначала LINEPROTO, потом LINK-3-UPDOWN) — воспроизводить дословно.
