## Цель для обучающегося

Обучающийся должен научиться по приглашению командной строки (`Switch>`, `Switch#`, `Switch(config)#`, `Switch(config-if)#`) определять, в каком режиме он находится, знать команды перехода вверх по иерархии (`enable`, `configure terminal`, `interface …`) и усвоить правило: если правильная команда даёт ошибку — проверь приглашение, ты, скорее всего, не в том режиме.

Текст (2.2.1–2.2.2) даёт таблицу двух EXEC-режимов и описывает режим глобальной конфигурации и два вложенных (line, interface). Видео добавляет: (1) как физически попасть в CLI в Packet Tracer — PC1 → Desktop → Terminal, параметры 9600/8/None/1/None; (2) что при запуске консоли виден вывод загрузки IOS и нужно нажать Enter; (3) живую смену приглашения при каждом переходе; (4) типичную ошибку новичка — команда не в том режиме. Переходы вниз (`exit`, `end`, `disable`) видео не показывает — это следующий ролик 2.2.5.

## Сценарий

Топология Packet Tracer: **PC1** — **Switch1** (2960), два кабеля: консольный (голубая дуга, RS-232 ↔ Console) и медный прямой (PC1 FastEthernet0 ↔ Switch1 Fa0/4 — по сообщению `%LINK-5-CHANGED: Interface FastEthernet0/4`). Имя узла в CLI — заводское `Switch` (метка устройства на схеме — Switch1).

## Предложение по пересборке

**Формат:** `видео с генерированным голосом (код-рендер)` — рендер терминала с подсветкой приглашения при каждой смене режима, ~1:30. В паре с 2.2.5 (Z-n1tO4Xg6w) можно объединить в один ролик «Режимы IOS: вверх и вниз» ≈ 3:00; по отдельности — этот ролик про «вверх», следующий — про «вниз и напрямую между вложенными». Для симулятора — сессия ниже без изменений (плюс короткий вывод загрузки по желанию).

Сцены для генератора:

1. **Схема** → PC1 —(консоль)— Switch1, подпись «консольный кабель, 9600 8-N-1» → «Подключаемся к коммутатору через консоль. После загрузки IOS просит нажать Enter.»
2. **`Switch>`** → крупно приглашение, подсветка символа `>` → «Знак „больше“ — пользовательский режим EXEC: только просмотр, команд мало.»
3. **`enable`** → ввод, приглашение становится `Switch#`, подсветка `#` → «enable — привилегированный режим EXEC: доступны все команды просмотра и управления.»
4. **`configure terminal`** → строка-подсказка `Enter configuration commands…`, приглашение `Switch(config)#` → «configure terminal — режим глобальной конфигурации, здесь делается большинство настроек.»
5. **`interface vlan 1`** → `Switch(config-if)#` → «Вложенный режим — конфигурация интерфейса: в скобках после config появляется if.»
6. **Схема режимов** → лесенка `>` → `#` → `(config)#` → `(config-if)#` с командами на стрелках → «Чем ниже, тем больше прав и уже контекст.»
7. **Правило** → в терминале пример: `Switch>configure terminal` → `% Invalid input detected at '^' marker.` (добавить к оригиналу!) → «Если команда верна, но IOS ругается — посмотрите на приглашение: вы не в том режиме.»

Ассеты: рендер терминала (моноширинный, чёрный фон), схема-лесенка режимов, мини-топология PC1–Switch1 с консольным кабелем.

**Сессия для симулятора** (как в видео; строки в `[]` — по голосу/контексту):

```
[вывод загрузки 2960 … ]
Press RETURN to get started!

%LINK-5-CHANGED: Interface FastEthernet0/4, changed state to up

%LINEPROTO-5-UPDOWN: Line protocol on Interface FastEthernet0/4, changed state to up

Switch>enable
Switch#configure terminal
Enter configuration commands, one per line.  End with CNTL/Z.
Switch(config)#interface vlan 1
Switch(config-if)#
```

Дополнение для тренажёра (иллюстрация «не тот режим», в видео только словами):

```
Switch>configure terminal
          ^
% Invalid input detected at '^' marker.
Switch>
```

**Замечания к оригиналу:** на схеме устройство подписано `Switch1`, а имя узла в CLI — `Switch` (не настроено); сообщение о «не том режиме» только проговаривается, на экране ошибки нет — при пересборке показать. Фактических ошибок нет.
