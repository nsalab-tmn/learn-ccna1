## Цель для обучающегося

Обучающийся должен уверенно перемещаться между режимами: `enable`/`disable` между EXEC-режимами, `configure terminal` (`config t`) вниз, `exit` на уровень вверх (и знать, что `exit` из privileged EXEC закрывает консольную сессию), `end` или Ctrl+Z — сразу в privileged EXEC из любого вложенного режима; уметь входить в `line console 0`, `line vty 0 15`, `interface vlan 1`, `interface fastethernet 0/1` и переходить между ними напрямую, не возвращаясь в global config.

Текст 2.2.4 перечисляет те же команды с тремя короткими примерами. Видео добавляет: (1) что `exit` из `Switch1#` выбрасывает из консоли (`Switch1 con0 is now available / Press RETURN to get started.`) и как вернуться; (2) сокращение `config t`; (3) `line vty 0 15` как вход в режим виртуальных терминалов; (4) правило «команды global config работают и из вложенных режимов» — именно поэтому можно переходить напрямую `(config-line)#` → `(config-if)#` → `(config-line)#`; (5) сообщение `%SYS-5-CONFIG_I: Configured from console by console` после каждого выхода в privileged EXEC.

## Предложение по пересборке

**Формат:** `видео с генерированным голосом (код-рендер)` ~2:30, рендер терминала + сбоку живая схема-лесенка режимов, на которой подсвечивается текущий режим и стрелка выполняемой команды. Можно объединить с 2.2.3 (B269UlVAN40) в один ролик ≈ 3:00. Для симулятора — полная сессия ниже; это идеальный первый тренинг «навигация по режимам» с проверкой приглашения после каждой команды.

Сцены для генератора:

1. **Лесенка режимов** → `Switch1>` · `Switch1#` · `Switch1(config)#` · `(config-line)#` / `(config-if)#` → «Четыре уровня; команды перемещения — на стрелках.»
2. **enable / disable** → терминал: `enable` → `#`, `disable` → `>` → «enable — вверх по привилегиям, disable — обратно.»
3. **configure terminal / exit** → `configure terminal` → `(config)#`; `exit` → `#` + `%SYS-5-CONFIG_I` → «exit поднимает на один уровень.»
4. **exit из `#`** → `exit` → экран `Switch1 con0 is now available / Press RETURN to get started.` → Enter → «Из privileged EXEC exit закрывает консольную сессию — не пугайтесь, Enter возвращает.»
5. **config t** → `config t` → `(config)#` → «Команды можно сокращать: config t.»
6. **Вложенные режимы** → `line console 0` → `(config-line)#`; `exit`; `line vty 0 15` → `(config-line)#` → «line console 0 — консоль; line vty 0 15 — 16 виртуальных линий для удалённого доступа.»
7. **Напрямую** → `interface vlan 1` → `(config-if)#`; `interface fastethernet 0/1` (приглашение то же); `line console 0` → `(config-line)#` → «Между вложенными режимами можно переходить напрямую — команды global config работают отовсюду.»
8. **end / Ctrl+Z** → `end` → `#`; `config t` → `line console 0` → `^Z` → `#` → «end или Ctrl+Z — сразу в privileged EXEC из любой глубины.»

Ассеты: рендер терминала; схема-лесенка режимов с анимируемой подсветкой; таблица команд (enable, disable, configure terminal, exit, end, Ctrl+Z, line console 0, line vty 0 15, interface vlan 1, interface fastethernet 0/1).

**Сессия для симулятора** (дословно по экрану; `^Z` — нажатие Ctrl+Z, отображается как `^Z`):

**Замечания к оригиналу:** фактических ошибок нет. Авто-субтитры дают «the n command» вместо «the end command» и «in able» вместо «enable» — в транскрипте ниже оставлено как есть. На экране приглашение `(config-if)#` не показывает имя интерфейса — при пересборке подписать, что после `interface fastethernet 0/1` приглашение не меняется, и это нормально.
