## Цель для обучающегося

Понять, что при отправке пакета в **другую** сеть хост всё равно использует ARP, но ищет MAC-адрес не получателя, а **шлюза по умолчанию**: PC-A сравнивает 10.1.1.10 со своей сетью → адрес удалённый → нужен MAC для 192.168.1.1 (Default Gateway) → ARP-кеш пуст → пакет на удержании → широковещательный ARP-запрос «Target IPv4 192.168.1.1» → PC-B и PC-C молчат, отвечает R1 (MAC 00-0D) unicast-ответом → PC-A кеширует «192.168.1.1 → 00-0D» и отправляет кадр с Destination MAC 00-0D, тогда как Destination IP в пакете остаётся 10.1.1.10.

Текст темы 9.2.5 формулирует правило (другая сеть → MAC шлюза; хост сравнивает адреса назначения и свой, ищет запись шлюза в ARP-таблице) и ссылается на видео за самим процессом. Видео добавляет полный прогон с конкретными адресами и поле «Default Gateway: 192.168.1.1» в настройках PC-A; ключевая картинка для учащегося — финальный кадр, где **MAC назначения = роутер, IP назначения = удалённый хост** одновременно. Это замыкает тройку 9.2.3/9.2.4/9.2.5 и напрямую готовит тему 10.3 (шлюз по умолчанию).

**Замечания о точности оригинала (учесть при пересборке):**

1. В полоске ARP-ответа поля подписаны «Target IPv4 / Target MAC», тогда как в ролике 9.2.4 те же поля назывались «Sender IPv4 / Sender MAC» (что правильно для ответа — отправитель сообщает свои адреса). Диктор тоже говорит «target». В пересборке использовать единую и корректную терминологию: в ответе — Sender IPv4/MAC = адреса R1, Target IPv4/MAC = адреса PC-A.
2. На линии R1 → Internet на протяжении всего ролика висит знак ⊘ (он уместен в 9.2.3 — «роутер не пересылает ARP-запрос»), но здесь сбивает с толку: кадр как раз должен уйти через R1 в сторону 10.1.1.10. В пересборке знак не показывать, а финальной сценой показать, что R1 снимает заголовок Ethernet и маршрутизирует пакет дальше.
3. Диктор проглатывает адрес назначения («destination ip address 10.1»); на схеме — 10.1.1.10. Использовать 10.1.1.10.
4. Не показано, что R1, получив ARP-запрос, сам заносит PC-A в свою ARP-таблицу (это видно потом в `show ip arp`) — добавить фразой; это свяжет анимацию с CLI в 9.2.7.
