## Цель для обучающегося

Понять вторую половину ARP-обмена: узел-цель (PC-C) формирует ARP-ответ с полями **Sender IPv4 / Sender MAC** и отправляет его **unicast** на MAC инициатора; инициатор (PC-A) заносит пару «IPv4 → MAC» в свой ARP-кеш, снимает отложенный пакет с удержания, вписывает найденный MAC в поле Destination MAC заголовка Ethernet и только теперь отправляет кадр.

Текст темы 9.2.4 описывает заголовок ARP-ответа (destination MAC = отправитель запроса, source MAC = отвечающий, Type 0x806), unicast-доставку, добавление записи в таблицу и отбрасывание пакета при отсутствии ответа. Видео добавляет наглядную «механику»: заполнение строки ARP-кеша `192.168.1.50 → 00-0C`, возврат отложенного пакета и подстановку MAC в ячейку «Destination MAC ???» → «00-0C». Чего в видео нет, но есть в тексте: таймаут записей, статические записи, отбрасывание пакета без ответа, аналогия с ICMPv6 ND.

## Сценарий

Та же схема, что в 9.2.3: коммутатор в центре; **PC-A 192.168.1.110 / 00-0A** слева, **PC-B 192.168.1.120 / 00-0B** сверху, **PC-C 192.168.1.50 / 00-0C** справа, **R1 192.168.1.1 / 00-0D** снизу, на линии R1 → «Internet» знак ⊘ (остался от предыдущего видео). Слева вверху таблица «PC-A's ARP Cache» (IPv4 Address / MAC Address). Внизу две полоски: верхняя — текущий кадр, нижняя (бледная, под пунктиром, подпись «On Hold») — отложенный IP-пакет «Destination MAC ??? · Source MAC 00-0A · Source IP 192.168.1.110 · Destination IP 192.168.1.50».

**Замечания о точности оригинала (учесть при пересборке):**

1. Как и в 9.2.3, в кадре не показано поле Type 0x806 (текст 9.2.4 его описывает).
2. В ARP-ответе показаны только Sender IPv4/Sender MAC; реальный ответ несёт и Target IPv4/MAC (адрес PC-A). Для курса допустимо, но при пересборке можно показать все четыре поля ARP-полезной нагрузки — это проще связать с Wireshark-захватом в лабораторной 9.2 и с симулятором.
3. Видео не показывает, что PC-C тоже пополняет свой ARP-кеш из полей Sender запроса (и поэтому его ответный трафик не требует нового ARP-запроса) — стоит добавить одной фразой.
