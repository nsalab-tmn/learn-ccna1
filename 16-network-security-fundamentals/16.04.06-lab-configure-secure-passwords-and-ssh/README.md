## Описание сценария

Сетевое устройство с настройками по умолчанию защищено слабо: пароли хранятся в его конфигурации открытым текстом, а протокол Telnet передает по сети и пароль, и все команды без шифрования. Поэтому перед подключением к сети на маршрутизаторе и коммутаторе шифруют пароли, задают пароль привилегированного режима EXEC в виде хеша, ограничивают попытки входа и разрешают удаленное управление только по протоколу SSH, который шифрует весь сеанс. Для работы SSH устройству нужны имя устройства, доменное имя, ключи RSA и локальная учетная запись пользователя.

Согласно сценарию, администратор сети поручил вам подготовить к развертыванию маршрутизатор RTA и коммутатор SW1 небольшого офиса. Устройства еще не настроены, а к консольному порту маршрутизатора кабелем подключен компьютер администратора PCA. Вам нужно настроить IP-адресацию компьютера PCA, основные параметры безопасности и доступ по SSH на маршрутизаторе и коммутаторе, сохранить их конфигурацию и убедиться, что устройства доступны по SSH, а подключение по Telnet отклоняется.

## Задачи лабораторной работы

- Настроить IP-адресацию компьютера PCA
- Настроить основные параметры безопасности маршрутизатора RTA
- Настроить доступ к маршрутизатору RTA по протоколу SSH
- Настроить основные параметры безопасности коммутатора SW1
- Настроить доступ к коммутатору SW1 по протоколу SSH
- Проверить связь и подключение к устройствам по SSH

## Описание топологии

Топология состоит из маршрутизатора RTA, коммутатора SW1 и компьютера PCA: компьютер подключен к коммутатору, коммутатор — к маршрутизатору, а консольный кабель соединяет компьютер PCA с консольным портом маршрутизатора.
