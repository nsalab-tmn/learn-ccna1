## Описание сценария

Протоколы транспортного уровня TCP и UDP доставляют данные приложений между узлами. TCP перед передачей данных устанавливает соединение, нумерует передаваемые байты и подтверждает их получение, а UDP отправляет каждое сообщение отдельно, без соединения и подтверждений. По номерам портов узел определяет, какому приложению предназначены данные, поэтому данные нескольких приложений могут одновременно передаваться по одной сети: это мультиплексирование.

Согласно сценарию, в небольшой сети компании сервер MultiServer отдает веб-страницу и отвечает на DNS-запросы, а компьютеры сотрудников обращаются к нему из веб-браузера и командной строки. Сеть уже настроена. Вам, специалисту службы поддержки, нужно в режиме «Симуляция» проследить, как запрос веб-страницы и DNS-запрос одновременно передаются по сети, и сравнить заголовки TCP и UDP в единицах данных протокола (PDU) этих обменов.

## Задачи лабораторной работы

- Пронаблюдать мультиплексирование трафика HTTP и DNS
- Изучить заголовок TCP в обмене HTTP
- Изучить заголовок UDP в обмене DNS
- Проверить работу веб-службы в режиме «Лаборатория»

## Описание топологии

Топология состоит из сервера MultiServer, коммутатора Switch и компьютеров HTTP-Client, FTP-Client, E-Mail-Client и DNS-Client.
