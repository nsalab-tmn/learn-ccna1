# compute/local — netsim node on the `local` (docker) compute kind

Terraform (kreuzwerker/docker) that runs one `learn-netsim` container on the shared
`learn-labs` network and emits the SSH address the grader uses.

- **Provider** `docker` reads `DOCKER_HOST` from the environment (the scoped
  socket-proxy wired by learn-infra) — no provider config here.
- **Network** attaches to the external `learn-labs` network by name (a cross-repo
  contract); `learn-assessment` is on the same network and reaches the node by IP.
- **Outputs → `tf-dynamic-params.json`** (raw `terraform output` envelope, written by
  learn-lab-deploy): `lab_ip` (learn-labs IP — **never localhost**), `lab_host`
  (container name / Docker DNS), `ssh_port_<DEVICE>` (one per simulated device:
  2200 + its topology id — the grader's testbed uses these), `ssh_port` (22, legacy alias
  of the first device), `ssh_user`, `ssh_password`
  (per-lab random), and `URL` (the web canvas for the learner: the lab topology,
  click a simulated device to open its console in the page).
- **Image** `var.netsim_image` (default `ghcr.io/nsalab-tmn/learn-netsim:latest`),
  `keep_locally` so an already-present image isn't re-pulled (offline/e2e).
- **Topology** `topology.yaml` (here, because lab-deploy stages only this
  directory) is uploaded into the container at `/app/topology.yaml` and read via
  `NETSIM_TOPOLOGY`. It is generated by learn-netsim `labs/build.py` from
  `labs/ccna1/14.8.1/spec.py` and copied here unchanged; the schema is documented in learn-netsim
  `material/netsim-secure-ssh-lab/compute/local/topology.yaml`.

Each device boots from its `config:` in `topology.yaml` (the part the lab ships
configured), so only what the learner configures on top is graded; `NETSIM_ENABLE_WEB=1`
serves the canvas and its consoles from the same daemon the grader hits over SSH.
